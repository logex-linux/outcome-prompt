# outcome-prompt · 三度提示词

为 AI 起草、改写或诊断任务提示词的技能。适用于「帮我写个提示词」「优化这段 prompt」「把这个需求变成可复制的指令」，以及按高度、深度、广度重写。

核心原则：把需求转成明确的结果、可执行的方法和可检验的交付。只在用户要提示词时使用；直接交付任务时不改成写提示词。

## 方法

- **高度**：说清事情做成后要发生什么——谁用结果、理解什么、做什么决定。区分最终目的和本轮交付。
- **深度**：把专业水平写成能执行和核验的动作——熟手从哪里入手、用什么方法、留下什么证据。
- **广度**：用动词定义使用场景，必要时借用相邻领域的方法补证据、方案或验收缺口。

交付前按「目标与受众、输入、执行要求、交付、验收」组织；缺失或冲突的数据要显式处理，不能把模型自评当成独立证据。

## 文件结构

- `SKILL.md`：技能主体与交付前检查
- `references/examples.md`：从原始需求到可执行提示词的改写样例
- `references/sources.md`：框架来源与中文转述说明

## 使用

先读 `SKILL.md`。需要参照成稿时读 `references/examples.md`，需要核对框架和出处时读 `references/sources.md`。

安装方式：将本目录放到 Agent 的 skills 目录（如 `~/.agents/skills/outcome-prompt/`），由宿主按需加载。
